Clipnyx is a menu bar clipboard history manager.

Basic usage:
1. Launch the app — it appears in the menu bar. (No permission dialog is shown at launch.)
2. Open the history panel from the menu bar icon or with ⌘+Shift+V.
3. Selecting an item copies its content to the clipboard.

About the Accessibility (PostEvent) permission:
- It is used ONLY for the optional "direct paste" convenience (sending ⌘V to the
  frontmost app so the selected item is pasted automatically).
- It is NOT requested at launch. It is requested only the first time the user
  performs a direct paste, after an in-app explanation of why it is needed.
- The app is fully functional WITHOUT this permission: items are copied to the
  clipboard and the user can paste them manually with ⌘V. Direct paste can also be
  turned off in Settings.
- Implementation uses CGEvent.post() to send the ⌘V keystroke. It does NOT use the
  Accessibility API (AXUIElement / AXIsProcessTrusted).

You can test all features without granting any permission (copy + manual ⌘V).
